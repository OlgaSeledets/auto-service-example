# AutoElectro — демонстрационный лендинг

Адаптивный одностраничный сайт автосервиса по диагностике и ремонту автоэлектрики.

## Содержимое

- `index.html` — структура страницы и тексты
- `assets/css/styles.css` — оформление, адаптивность и анимации
- `assets/js/script.js` — мобильное меню, модальные окна, навигация и анимации
- `assets/images/` — **локальные** изображения (не требуют подключения к сторонним сайтам)
- `assets/icons.svg` и `assets/favicon.svg` — векторные иконки
- `.github/workflows/deploy.yml` — автоматическая публикация GitHub Pages
- `.nojekyll` — отключение обработки Jekyll

## Как открыть

Для быстрого просмотра дважды нажмите `index.html`. Для полноценного локального просмотра (корректной загрузки всех SVG-иконок) запустите из папки проекта:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000`.

## Как опубликовать на GitHub Pages

1. Создайте **публичный** репозиторий на GitHub (например, `autoelectro`).
2. Распакуйте архив и загрузите **содержимое папки** `autoelectro-site` в корень репозитория (`index.html` должен быть в корне).
3. Назовите главную ветку `main` (либо поменяйте её название в `.github/workflows/deploy.yml`).
4. Откройте **Settings → Pages → Build and deployment → Source: GitHub Actions**.
5. После выполнения workflow `Deploy static site to GitHub Pages` сайт будет доступен по адресу `https://ВАШ_ЛОГИН.github.io/autoelectro/`.

**Важно:** адрес, телефон, email и название AutoElectro — демонстрационные данные. Замените их перед реальным использованием в `index.html`. Контакты в форме не собираются — кнопки ведут к контактам или открывают звонок.

## Особенности

- Без фреймворков, сборки, пакетов и API: работает как статический сайт.
- Меню для мобильных устройств, модальные окна услуг, плавный скролл, анимации при появлении элементов.
- `prefers-reduced-motion` — поддержка системной настройки уменьшения анимаций.
- Семантический HTML, подписи к изображениям, клавиатурное управление и базовое SEO.
- Картинки созданы для демонстрационного проекта.
